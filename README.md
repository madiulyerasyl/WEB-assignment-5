# Assignment 5 — JavaScript Basics

## Description

This is my Assignment 5 project for Web Technologies. In this assignment, I practiced JavaScript basics, DOM manipulation, and event handling.

## Tasks

- **Task 0:** First JavaScript Script
- **Task 1:** Variables and Operators
- **Task 2:** Changing HTML Content
- **Task 3:** Changing CSS Styles
- **Task 4:** Creating and Removing Elements
- **Task 5:** Mouse Events
- **Task 6:** Keyboard Events
- **Task 7:** Simple Calculator
- **Task 8:** Interactive To-Do List

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use Live Server.
4. Use the navigation bar to switch between tasks.

## Features

The project includes interactive buttons, dynamic text and style changes, mouse and keyboard events, a calculator, and a To-Do List.

The To-Do List allows users to add, complete, and delete tasks. Tasks are stored temporarily in a JavaScript array.
